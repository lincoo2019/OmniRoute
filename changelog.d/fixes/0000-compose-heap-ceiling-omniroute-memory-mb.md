- **fix(docker):** `docker-compose.yml` no longer hard-codes `NODE_OPTIONS=--max-old-space-size=2048`. That literal shadowed the documented `OMNIROUTE_MEMORY_MB` knob — `scripts/dev/run-standalone.mjs` keeps an explicit `NODE_OPTIONS` value whenever `OMNIROUTE_MEMORY_MB` is unset (#5238) — so every Compose host ran the same heap regardless of its RAM. On a 2 GB VPS the overshoot pushed the host into swap, spiked memory PSI and tripped the resource-pressure guard, which then answered every provider with `503 resource_pressure` ("Service temporarily unavailable due to resource pressure"). Compose now derives the ceiling from `OMNIROUTE_MEMORY_MB` and defaults to 1024 (1 GB → 512, 2 GB → 1024, 4 GB → 2048). The standalone launcher additionally warns at boot when the effective heap leaves less than ~320 MB of the container's memory limit for native/OS allocations (#2939), so the misconfiguration is visible instead of looking like an upstream outage.
